# 02. 분석서

## 도메인

핵심 도메인은 `학습노트`다. 노트는 제목, 본문, 상태, 태그, AI 생성 결과를 가진다.

## 사용자 흐름

1. 계정 생성
2. 로그인
3. 노트 작성
4. 태그 등록
5. 요약 또는 질문 생성
6. 대시보드에서 최근 학습과 통계 확인

## 데이터 분석

- `users`: 인증 주체
- `learning_notes`: 학습 기록 본문
- `tags`: 분류 기준
- `note_tags`: 노트와 태그의 다대다 연결
- `ai_outputs`: 요약 또는 질문 생성 결과

## AI 처리 분석

- 기본값은 `mock` provider다.
- 실제 provider는 API 키와 모델 정책을 확인한 뒤 활성화한다.
- 요약과 질문 생성은 같은 입력을 쓰지만 출력 목적이 다르므로 결과 유형을 분리해 저장한다.

## 리스크

- AI 출력 품질은 입력 품질과 모델 설정에 영향을 받는다.
- 외부 AI API는 비용과 응답 지연이 발생할 수 있다.
- 프론트엔드 문구가 과장되면 포트폴리오 신뢰도가 낮아질 수 있다.
