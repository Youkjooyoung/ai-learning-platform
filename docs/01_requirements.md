# 01. 요구사항정의서

## 사용자

- 개인 학습자
- 포트폴리오를 정리하는 개발자 지망생
- 학습 기록을 요약하고 복습 질문으로 바꾸고 싶은 사용자

## MVP 범위

- 회원가입, 로그인, 내 정보 조회
- 학습노트 생성, 조회, 수정, 삭제
- 태그 등록 및 필터링
- 학습노트 요약 생성
- 복습 질문 생성
- 대시보드 요약 조회

## 기능 요구사항

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| FR-001 | 사용자는 계정을 만들 수 있다. | Must |
| FR-002 | 사용자는 로그인 후 토큰을 받을 수 있다. | Must |
| FR-003 | 사용자는 학습노트를 작성할 수 있다. | Must |
| FR-004 | 사용자는 자신의 학습노트만 조회, 수정, 삭제할 수 있다. | Must |
| FR-005 | 사용자는 노트에 태그를 붙일 수 있다. | Must |
| FR-006 | 사용자는 노트 본문을 요약할 수 있다. | Should |
| FR-007 | 사용자는 노트 본문에서 복습 질문을 만들 수 있다. | Should |
| FR-008 | 사용자는 총 노트 수, 태그 수, 최근 노트를 볼 수 있다. | Should |

## 비기능 요구사항

- API는 `/docs`에서 OpenAPI 문서를 확인할 수 있어야 한다.
- 로컬 개발은 Docker Compose로 실행할 수 있어야 한다.
- 비밀키는 저장소에 커밋하지 않는다.
- UI 문구는 기능 라벨 중심으로 제한한다.
- AI provider가 없을 때도 mock 응답으로 기능 흐름을 검증할 수 있어야 한다.

## 제외 범위

- 결제
- 팀 협업
- 실시간 공동 편집
- 모바일 앱 구현
- 운영용 Kubernetes 배포
