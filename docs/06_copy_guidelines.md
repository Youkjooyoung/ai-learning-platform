# 06. UI 문구 기준

## 원칙

- 화면은 설명하지 않고 기능을 제공한다.
- 문구는 짧게 쓴다.
- 홍보형, 감성형, 과장형 문장을 쓰지 않는다.
- 첫 화면은 랜딩페이지가 아니라 실제 작업 화면이다.

## 사용 가능

- 새 노트
- 저장
- 삭제
- 요약
- 질문 생성
- 최근 학습
- 태그
- 상태
- 검색
- 로그인
- 회원가입

## 사용 금지

- 추상적인 개선 약속
- 감성적인 성장 문구
- 근거 없는 자동화 표현
- 제품 설명을 반복하는 긴 문장
- 마케팅 랜딩페이지식 가치 제안

## 점검 기준

- 버튼 문구가 동작을 정확히 말하는가
- 빈 상태 문구가 과장되지 않았는가
- 화면 상단에 마케팅 카피가 없는가
- 문구 없이 UI 구조만으로 이해 가능한 곳에 설명문을 넣지 않았는가
